# Система извлечения именованных сущностей (NER)

Это проект, разработанный в качестве тестового задания, демонстрирующий полный цикл создания и применения модели для извлечения именованных сущностей (NER), с особым акцентом на сущность `PROFESSION`. Решение включает в себя этапы от обработки данных и обучения кастомной модели до гибридного инференса, сочетающего нейросетевой подход и правила.

## ✨ Ключевые особенности

*   **Гибридный подход к извлечению:** Система использует комбинацию из двух методов:
    1.  **Fine-tuned BERT модель:** Для точного распознавания сущностей, которым модель была обучена (в частности, `PROFESSION`).
    2.  **Лингвистические правила:** Для извлечения общих именных групп (Noun Phrases), что позволяет находить потенциальные сущности, даже если они не были размечены в обучающих данных.
*   **Кастомная функция потерь:** В процессе обучения используется модифицированный `Trainer` (`PrecisionOrientedTrainer`), который добавляет к основной функции потерь (Cross-Entropy) штраф за ложноположительные срабатывания на класс `PROFESSION`. Это позволяет сместить баланс модели в сторону более высокой точности (precision), что является требованием в данной задаче.
*   **Автоматический подбор гиперпараметров:** Интеграция с `Optuna` для поиска оптимальных параметров обучения.
*   **Воспроизводимость:** Четкие инструкции по установке зависимостей и запуску всех этапов жизненного цикла модели.


## 💾 Данные и их анализ

Для обучения используется датасет **NEREL** (`HSE/nerel_dataset/data/NEREL-v1.1/`), представленный в формате **BRAT**.

Для анализа распределения сущностей в обучающем наборе данных можно использовать скрипт `data_exploration.py`. Он проходится по аннотациям и генерирует отчеты о частоте встречаемости каждого класса, что помогает лучше понять данные перед обучением.

## 튜 Подбор гиперпараметров

Для достижения наилучшего качества модели критически важно подобрать оптимальные гиперпараметры. В проекте эта задача автоматизирована с помощью скрипта `HSE/params_eval.py` и библиотеки `Optuna`.

Скрипт ищет комбинацию следующих параметров, которая максимизирует метрику `precision` на валидационном наборе:
*   `learning_rate`
*   `per_device_train_batch_size`
*   `num_train_epochs`
*   `weight_decay`
*   `penalty_weight` (коэффициент штрафа в кастомной лосс-функции)

Для запуска процесса оптимизации выполните:
```bash
python HSE/params_eval.py
```
По завершении скрипт выведет в консоль лучшие найденные параметры и соответствующее им значение `precision`. Эти параметры затем можно использовать для финального обучения модели.

## 🧠 Обучение модели

### Концепция

Скрипт `HSE/train.py` выполняет fine-tuning модели `DeepPavlov/rubert-base-cased` на задаче NER с *фиксированными* гиперпараметрами (в отличие от `params_eval.py`).

1.  **Загрузка данных:** Данные из формата BRAT загружаются и преобразуются в `Dataset` объект библиотеки Hugging Face.
2.  **Токенизация и выравнивание:** Тексты токенизируются с помощью `BertTokenizerFast`. Метки (tags) выравниваются относительно полученных токенов (WordPiece-токенов).
3.  **Кастомный тренер:** Используется `PrecisionOrientedTrainer` с его кастомной функцией потерь для повышения `precision`.
    \[ \mathcal{L} = \mathcal{L}_{CE} + \lambda \cdot P(\text{PROF|Non-PROF}) \]
4.  **Обучение:** Модель обучается с использованием `Trainer` API и `EarlyStoppingCallback`.

### Запуск

Перед запуском рекомендуется сначала найти оптимальные гиперпараметры с помощью `params_eval.py`, а затем внести их в скрипт `train.py`.

Для запуска процесса обучения выполните:
```bash
python HSE/train.py
```
По завершении обученная модель будет сохранена в директорию `ner_profession_model/`.

## 🔬 Инференс (применение модели)

### Концепция

Скрипт `HSE/main.py` реализует гибридный подход для извлечения сущностей.

1.  **NER-извлечение:** Текст обрабатывается обученной моделью. Для длинных текстов используется стратегия "скользящего окна" (`sliding window`).
2.  **NP-извлечение (Noun Phrase):** Параллельно текст анализируется `spaCy` с `benepar` (если доступен) и `Matcher`'ом для поиска именных групп.
3.  **Слияние спанов:** Результаты объединяются, при этом NER-спаны имеют приоритет над NP-спанами при пересечении.

### Запуск

1.  **Подготовьте данные:** Убедитесь, что в корневой директории проекта (`project/`) находится файл `test_texts.xlsx`.
2.  **Укажите путь к модели:** В скрипте `HSE/main.py` убедитесь, что переменная `model_checkpoint` указывает на вашу обученную модель (например, `ner_profession_model/`).
3.  **Запустите скрипт:**
    ```bash
    python HSE/main.py
    ```
4.  **Получите результат:** Результаты будут сохранены в файл `test_texts_inference.json`.
